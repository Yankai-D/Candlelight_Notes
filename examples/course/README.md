# 课程讲义模板与基准

`course-lecture-v1` 是允许跨教材、课件重组的文档任务。新的调用默认采用“结构化讲义”，也可提供 `writingTemplate` 快照，沿用与单文件适应学习相同的模板库。长文讲述与结构化讲义有不同的组织规范；稳定画像决定铺垫深度，学习目标决定范围内的重点与用途，两者都不暗自改变选定模板。阅读记录、资料库状态、学习树不进入背景推断。旧 `writingStyle` 调用仍保留原有长文协议，不能将它当作新版模板设置的入口。

## 编写规范

跨文件任务的规则在 [course-policy.mjs](../../shared/course-policy.mjs)，包括覆盖、来源、合成算例、条件与冲突处理。模板的组织规范与两套默认样稿在 [writing-templates.mjs](../../shared/writing-templates.mjs)。长文把背景、直觉与推导融入连续叙述；结构化讲义按知识依赖安排标题、定义、条件、计算和例子，各单元便于独立回查，也保留充分解释。二者均要求交代数学细节的用途、依据与结论边界。

同一概念在教材与课件中只保留一个主要解释位置，独有信息不能随去重丢失。统一符号必须先辨明含义相同；条件冲突不能被语言润色掩盖。缺损公式与图像信息先核对，有依据的补充与原文结论分开标记。一次只生成一份讲义，试卷另建任务与验收规范。

## 基准样稿

运行 `npm.cmd run review:course`，打开 `output/course-lecture-reference.html` 或运行中的 <http://127.0.0.1:5173/review/course.html>。它复用 `noteBlocks → reading-tree-note-v1 → renderNoteHTML / MathJax`，没有第二套 Markdown 解释器。两种背景保留同一正文，只缩短已知计算；“核对来源”显示文件、选编页码、原始页码及短引文，不干扰正常阅读。

`descriptive-statistics/reference.mjs` 包含完整课程的覆盖规划和第二节的**人工**样稿，主线为均值、离散、异常值与统计量选择。其他小节尚无基准正文。样稿不是模型输出，也不是模型已经达到质量标准的证据。

来源是此前导入的 OpenIntro 公开教学资料。`sources.json` 保存可复现的页码映射、源 PDF 哈希及抽取文字，可用 `python scripts/extract-course-fixture.py` 从 `output/pdf/descriptive-statistics/` 的 PDF 重建。此公共测试夹具不读取用户笔记或 API Key。数值课件选编第 4、14、16 页为已知图像公式页，保持 `needsReview=true`；样稿引用教材对应定义，未解除这些页的核对状态。其他页可被文本流程处理，不表示已做通用图像语义识别。

书籍署名 David Diez、Mine Çetinkaya-Rundel、Christopher D Barr，来源 <https://www.openintro.org/book/os/>，许可 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)。两份课件由 Mine Çetinkaya-Rundel 编写、Curry Hilton 转制，采用 [CC BY-SA 3.0 US](https://creativecommons.org/licenses/by-sa/3.0/us/)，原始链接与署名保存在 `sources.json`。抽取文字未改写；样稿进行了中文改编、重组、合并及补充，按 CC BY-SA 3.0 发布，不表示 OpenIntro 背书。源材料与样稿的许可不扩展为项目代码的许可声明。

## Harness 执行边界

### 模板库与个人样稿

界面入口为“设置 → 模板风格”。内置长文讲述与结构化讲义，可额外添加三套自定义模板，总数上限五套。自定义模板由用户描述资料对象与组织模式，并在创建时调用模型改编固定示范素材，生成默认样稿；创建失败不保存半成品。两套内置模板不能删除或改写默认样稿。每套都有独立的默认／个人样稿选择、调整、恢复和一个撤销槽位；切换与恢复不调用模型。

`server/template-harness.mjs` 的 `template-style` / `create-template` 动作将模板描述、当前样稿、表达约定与用户要求送入独立协议。数学占位符各保留一次且不得跨单元移动，恢复后通过正文、纸条、导出共用的编译与公式校验。允许结构化标题及必要列表，不能把所有模板强制为无标题长文。失败最多修复一次，不保存无效结果；关闭或取消阻止提交，持久化事务核对修订号，防止多窗口或迟到响应覆盖新版本。这保障结构与公式保留，不宣称自动证明全部事实或教学质量。

模板库保存在 IndexedDB 的 `writing-templates-v1` 偏好，与知识画像和文档分开。旧 `course-style-v1` 中的个人样稿迁到长文讲述，原记录保留。长文默认样稿仍可由 `node scripts/sync-course-style-sample.mjs` 同步人工基准；结构化默认样稿另行编写，不拿长文样稿换一个标题来代替。

单文件适应学习在第一次整理前调用 `select-template`：输入目录、学习目标与全文分布式摘录，只能选择现有模板 ID。失败时不生成正文；重试成功后先保存完整模板及选中样稿，再逐章生成。续接、协作编辑与备份恢复使用笔记里的快照，不再查询可变模板库。已开始的旧笔记保留原规则；纯翻译不参与此流程。

跨文件生成输入可使用 `writingTemplate: templateSnapshot(library, selectedId, reason)`，默认选结构化讲义；规划、每节生成和最终结果携带相同快照。样稿中的统计主题、公式与数字只是表达示范，不是当前课程证据。来源与覆盖校验不会被个人偏好关闭。完整资料包生成入口仍未连接，此处不把单文件自动选模板当作已经完成跨文件成品提交。

### 生成与提交

`server/course-harness.mjs` 提供 `buildCourseMessages`、规划与小节校验、`runCourseLecture` 以及复用现有 DeepSeek 适配器的 `courseCompletion`。

1. 输入稳定画像、学习目标、带文件身份的来源页，以及已核对的主题清单。当前夹具的清单由人工制定；通用课程的自动资料识别、图像核对和覆盖清单生成尚未接通，不能把模型自己漏掉的清单当作完整性基准。
2. 模型生成知识依赖顺序和小节规划。每个约定主题必须恰有一个主要位置，并纳入必要证据。规划针对学习目标，但它是否真正回应目标仍须语义审读。
3. 按小节提供对应源页、全篇规划、主题验收点和已校验正文尾部，连续生成一份讲义。来源过大时明确失败，不静默截断；当前尚无任意大课程的检索与递归拆分。
4. 校验文件身份、页码、引文、主题归属、来源覆盖、连续段落和公式格式。只对结构失败修复当前步骤一次；网络错误和取消不触发额外模型修复。模型不会获得写文件或任意执行工具。
5. 所有小节成功后返回 `status: structurally-validated, semanticReview: required`。没有写入浏览器笔记、更新画像或改动学习树；资料包入口和带修订号的成品提交尚未连接。多文件来源保存在独立 `provenance`，不强塞进旧版单文件页码字段。

示例接口（只展示调用方式，不在测试或导入时执行）：

```js
const result = await runCourseLecture(request, {
  complete: courseCompletion(config),
  signal,
  onProgress: ({ stage, attempt }) => report(stage, attempt),
});
```

调用次数为一轮规划加每小节一轮生成；每步至多一次结构修复。底层 DeepSeek 适配器仍保留已有的截断预算重试。已有文档不会因本模块导入或规范升级而重新生成。

## 验收方法

自动检查必须全部通过：主题唯一覆盖、依赖顺序、跨文件页码、来源引文、公式语法、格式统一、失败原子性、取消和有限修复。`tests/course-harness.test.mjs` 还用独立数值计算核对人工样稿的均值、平方和、方差、标准差、四分位数和箱线图终点，并验证两种背景只删减铺垫。

结构通过后，逐项审读 `coursePolicy.reviewCriteria`，每项记录“通过／待修改”及具体段落依据，不取平均分来掩盖错误。事实、数值、条件、来源误归属任一错误都需修改；任何核心主题缺失也不能发布成品。至少对照两种画像和两个目标：初学者掌握概念、已有基础者复习判断；描述典型个体、理解累计总量。应改变解释投入与重点，保持文风和事实一致。

第一轮模型实验固定材料、模板版本、模型配置与输入目标，保留每步耗时、调用次数及脱敏错误；原始输出仅存本地评审文件，不写入用户笔记。先审本样稿对应小节，再检查全篇去重和承接。拒绝用“JSON 正确”“引文存在”“模型自评通过”替代教学质量审查。已用两份合成短材料实测 DeepSeek 的单文件分类与生成：研究论述选中长文讲述并返回连续正文，课件选中结构化讲义并返回知识标题与分段解释。该冒烟检查不代表完整公开课程的教学质量验收，也没有证明跨材料风格稳定性。
