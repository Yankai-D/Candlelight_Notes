# 跨安装笔记识别

## 用户行为

默认扫描系统文档目录下的“烛光笔记”、当前保存目录及手动确认记住的目录；启动后只执行一次自动发现，不持续监听整个文件系统。资料库和设置提供“识别已有笔记”，扫描当前目录及子目录，选择后直接关联现有文件。扫描、取消、关联都不调用模型，也不迁移其他应用的 Key、画像或偏好。

识别单位为 `note.candlelight.json` 和相邻的 `source.pdf/txt/md/json`，保留正文、各阅读版本、纸条、历史和原文文本。普通 PDF 与导出的包装格式 JSON 继续使用现有文件导入流程。分类和学习树不从另一应用配置自动复制。

## 边界与持久化

- 自动发现不早于旧 IndexedDB 迁移完成，不与迁移抢占同一个资料 ID。
- 新记录可加入；已有同路径跳过；同编号不同文件提示冲突；旧路径已失效的记录经手动确认重新关联。记录移除后保存轻量路径标记，下次启动不会加回；用户可手动恢复。
- 预览保存在服务内存，十分钟过期，最多八份；确认时重验文件摘要、路径与当前索引，整批校验通过才一次性写入索引。笔记文件不改写、不复制。
- 扫描跳过隐藏目录、链接、程序和配置区；每次最多 10,000 个目录项、16 层、1,000 份笔记，单份笔记不超过 64 MB，最多记住 32 个识别目录。无权限和坏文件会进入问题清单。
- 文件按保存格式严格校验；原文缺失仍保留笔记，只读打开时关闭编辑、纸条添加与自动生成。
- 两个应用共用同一文件时，以阅读时文件摘要检查过时写入，并通过同目录排他写入锁限制保存与删除；检测到其他应用修改会拒绝覆盖或删除。保存冲突提示导出当前修改后重新打开。已退出进程的遗留锁可在确认 PID 不存在后清理。此功能不提供实时协同合并。

## 验证

新增跨档案自动恢复、嵌套目录预览与确认、记住目录、移除后不加回、移动后关联、同 ID 冲突、损坏文件、链接拒绝、过期/伪造/变化后预览拒绝、跨应用过时和并发保存、缺失原文但保留版本的服务测试。浏览器覆盖真实扫描界面、取消、确认、重复项、缺失原文只读、窄屏布局，并断言模型调用为零。

完整工程检查与安装包验收记录在对应版本发布记录中；不对已有个人安装执行卸载，不把源码自用目录或用户文件放入公开包。
