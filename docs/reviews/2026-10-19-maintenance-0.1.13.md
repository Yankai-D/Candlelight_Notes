# 0.1.13：学习成果维护与可追溯生成

本轮用户授权落实资料维护、可恢复性与生成依据记录，并明确：长期使用反馈已在持续驱动产品，论文讲述模板是核心资产。交付保持现有生产文风，不新增付费评测或自动教学打分。

## 结果与范围

- 资料列表的移除默认保留原位置文件，记录与回收站可恢复；永久删除需再次确认，并检查文件是否被其他安装改过。对应生成记录随永久删除清理，独立备份不受影响。
- 整库备份覆盖原文、笔记版本、纸条、历史、画像、模板、分类、树及节点资产和生成记录。新配置目录恢复已验证原文字节一致及 Key 隔离；恢复到新目录，可返回原空间。
- 缺失原文可以重新选择，现有笔记不改写；保存冲突展示两份节选，可把当前完整修改另存，原盘版本保留。
- 请求前保存目标、画像、样稿和来源快照，记录真实请求次数与修复事件。格式校验通过和写入/人工认可明确分开，不补造旧记录。
- 用户原话、需求和回归入口形成证据索引，现有叙述策略及样稿与 0.1.12 逐字比对保持不变。已有 ResNet A/B 反馈仍是项目作者的局部阅读偏好；不改成独立教学评分。

## 本轮发现与修复

| 问题 | 处置与验证 |
| --- | --- |
| 部分备份可能被扫描成新笔记 | 未完成标志及独立空间标志；备份失败注入和返回旧空间测试 |
| 恢复后旧窗口可能继续写入或调用模型 | 空间标记失效返回 409；恢复期间阻止生成，HTTP 集成测试 |
| 缺失原文复制成功而索引保存失败 | 仅回滚本次创建的副本，原笔记字节不变，故障注入测试 |
| 删除笔记却遗留含学习内容的生成快照 | 永久删除校验并清理本空间相应记录，保留备份边界 |
| 设置异步加载和恢复导航导致验收竞争 | 浏览器等待实际入口及页面导航；首轮失败证据保留，修复后完整回归 |
| 恢复确认框沿用了不匹配的 CSS | 专用复选框布局，桌面及 390px 窄屏截图核查 |
| 保存新目录后维护能力标志丢失 | 保留设置能力字段，避免入口在同一窗口消失 |
| 空间标记误传给严格模型连接接口 | 标记仅加入生成及存储请求，补充真实浏览器保存/清除连接和 HTTP 记录回归；首次门禁作废并保留报告，修复提交后重跑 |

## 验证结果

源码 `af0b24465b4f12acedd24724b26343bbb5fc786e` 冻结后：338 项单元/集成测试、9 套浏览器流程、14 项门禁全部通过，前后源码指纹一致。新增浏览器回归包含 16 次编辑保存往返、4 次刷新、回收/恢复、原文关联及冲突另存；其堆内存样本只用于诊断，不能当作数小时无泄漏结论。

实际打包的桌面程序通过首次引导、三份公开资料、阅读、数学 PDF、待保存退出、重复启动和重启持久性检查。0.1.12 → 0.1.13 使用隔离合成数据验证升级与两次重启。发行审计核验 12063 个实际载荷文件及 ZIP 条目，仅带三份描述性统计资料和致谢，不含个人资料、画像、笔记或 Key。

本轮没有变更依赖图，锁文件只有项目版本号更新；沿用 0.1.12 的依赖审计记录，未把历史审计称作本轮重新联网扫描。原生产卸载宏逐字相同，沿用已保存的隔离清理实测。完整 NSIS 安装/卸载、快捷方式生命周期仍待空白 Windows 用户或 VM 验收。

API 真实调用为 0，自用环境只更新服务，保存连接文件摘要前后相同。公开安装包和源码自用环境各自保持数据隔离；没有推送 GitHub。

## 已知边界与后续门禁

当前本机单用户模式支持同服务内维护互斥及单笔记文件锁，不提供跨进程的整库快照事务。大备份有体积和数量上限，但没有取消接口；网络盘、断电耐久性、长时间堆增长和完整读屏器流程尚未验证。正式公开前仍需安装生命周期、签名/代码许可证决策和真实远程 CI；不以本机测试替代。

生成记录含来源上下文，应按个人学习资料保存；只保留最近记录，不作为永久审计日志。未记录结束状态可能来自中断，不推断成功。真实模型在新材料中的因果展开、覆盖和事实忠实仍需阅读核验。下一次模板改动优先从实际难读段落出发，冻结输入、对照同模型同预算，记录具体改善与回退理由。

本轮完成的是维护与追溯能力的工程交付，同时保留现有模板价值和长期使用证据。详细操作见 [空间恢复](../workspace-recovery.md)，质量方法见 [产品质量](../product-quality.md)，机器可读摘要见 [发布记录](../releases/v0.1.13.json)。
