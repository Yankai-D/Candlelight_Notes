# 0.1.15 原文配套保存与统一迁移复核

代码基线：`0fbe5b131e79717e76566defd41354eb8a09dfae`。本轮实现和复核由同一协作者完成，不是独立审计。范围为理想学习树删除、历史原文缺失、导入格式边界和统一迁移。没有修改讲述模板，也没有进行真实模型调用。机器可读结果见 [发布记录](../releases/v0.1.15.json)。

## 交付行为

| 需求 | 实现与验收 |
| --- | --- |
| 删除理想学习树 | 保存目标卡片和树内工具栏都有入口。确认后终止构建和资料查找，删除该树记录；不删除已导入的资料或其他重建版本。删除缺失记录幂等，不要求配置 Key。 |
| 识别笔记时保留原论文 | 旧目录导入仅存 `builtinId`，安装版缺少自用目录，导致识别到笔记却找不到 PDF。新导入将原文和笔记配套保存；历史记录在可信原文仍可访问时补齐 PDF。JSON 备份不冒充原文。 |
| 统一迁移 | 空目录预览、明确确认、复制与散列校验、持久化提交日志、切换索引、校验后清理旧副本。迁移包含回收记录、理想树和生成记录；不移动无关文件和外部导入源。 |
| 格式说明 | 支持可提取文字的 PDF、Markdown、TXT；JSON 是本工具的笔记备份格式。未增加 DOCX、PPTX 或 OCR 支持。 |

本机历史资料修复补齐 14 份原论文，逐一验证原文摘要和笔记未变化。个人路径、资料内容及逐文件摘要仅保留在忽略目录中的本机证据，不进入对外源码或安装包。用户尚未指定迁移目标，因此没有擅自移动个人资料库。

## 验证结果

- 完整 `check --require-clean`：353 项单元／集成测试、10 组浏览器流程、14 个阶段通过；开始与结束源码指纹一致。浏览器走真实 HTTP 检查删除、取消、持久化、迁移确认、旧窗口拒绝和重新打开。
- 迁移覆盖内容完整性、非空和重叠目录拒绝、链接拒绝、过期预览、复制中断、提交中断、旧文件外部修改保留。另用合成 PDF 和笔记执行实际 C 盘到 E 盘迁移，文件字节一致，旧受管副本清理成功。
- 最终打包程序验证空白配置引导、隔离窗口、单实例、阅读、中文和数学 PDF、退出保存与重启；0.1.14 → 0.1.15 的合成笔记和设置保留。上述测试未安装或卸载用户个人程序。
- 最终 ASAR／资源逐文件审计 12064 个载荷文件，并核对安装包和 ZIP 摘要。发行包仅含三份允许的 OpenIntro 描述性统计资料及致谢；没有个人资料、画像、笔记或 Key。

首次全量运行中旧浏览器选择器把新增删除按钮计入目标数量；修正为目标打开按钮后重跑全量通过。最终桌面测试在受限环境被 Windows 沙盒目录访问规则阻止，改在普通 Windows 环境以隔离配置完成。首次发行审计使用了旧程序的桌面报告而拒绝通过；补齐最终程序的独立启动报告后重跑通过。失败记录不视作成功验收。

## 边界

迁移要求独立空目录；没有跨安装的整库锁，需要关闭其他版本。其他安装若引用旧目录，须重新识别新位置。共享资料缓存不因删除某棵树而整体清除。来源已经不存在时保留缺失提示，不能恢复不存在的原文。网络盘、突然断电、完整 NSIS 安装／卸载与快捷方式生命周期不在本轮验证范围。

本轮没有改变依赖图，未重新进行联网依赖审计。安装包未签名，远程 CI 未运行。0.1.15 为本机已验证候选，尚未推送 GitHub；不会替换此前 0.1.14 的公开发布或历史摘要。
