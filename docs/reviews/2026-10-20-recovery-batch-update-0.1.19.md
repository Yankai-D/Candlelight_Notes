# 0.1.19 恢复机制、批量资料与桌面更新复核

代码基线：`966ecc49539096a9c2919908b70e22ddda579df6`。本轮实现与复核由同一协作者完成，不是独立审计。发布证据见[发布记录](../releases/v0.1.19.json)，运行契约见[恢复与导入设计](../operational-harness.md)。

## 需求与实现

集中恢复层先判断错误发生在传输、保存还是诊断阶段，再执行有界恢复。原子保存采用唯一临时文件，针对 Windows 共享锁最多重试替换七次，总退避约九秒；始终保存同一份结果，不删除旧文件、不因此重新调用模型。理想树把有效结果和阶段事件一起提交，存储失败不会进入格式修复。普通模型任务共享有限传输重试预算；理想树使用已有构建预算，实际请求包含 token 扩展，不叠加无限重试。诊断写入失败不否决有效输出，恢复日志只保留阶段、错误码、计数和结果，并限制体积。认证、证书、磁盘已满和持续无法保存等问题仍需停止或暂停。

导入新增多文件与整个文件夹选择，保留嵌套关系。批量默认仅保存原件和轻量记录，不解析正文、不调用模型、不逐文件生成笔记；单文件也可选此方式。独立笔记按当前包及后代全部来源提取正文，缓存后复用，可分别生成知识讲义和例题讲解。导入部分失败后只重试未完成项；同编号重放必须核对原件和记录。退出会等待当前文件保存并停止剩余批次，帮助快捷键不会丢失导入表单。

安装版启动后检查固定 GitHub 仓库的公开发布信息，按版本顺序筛选匹配的安装包，提供下载、稍后与跳过当前版本；检查失败不阻止使用。当前 0.x 包含已发布的预发布版。更新不会上传模型凭据或学习资料，不自动下载或执行安装程序。NSIS 目录回调优先复用已有程序目录和已登记的安装位置，首次选父目录只追加一层产品目录。

## 验证

- 冻结基线的 14 个检查阶段通过：384 项单元／集成测试、11 组浏览器流程与离线 harness 验证。零失败、零跳过，首尾源码指纹一致。本轮真实模型调用为零。
- 真实浏览器验证 30 份原件保留嵌套资料包、导入时不提取正文或生成笔记、创建两份独立笔记复用正文缓存、部分失败重试、退出等待当前文件，以及帮助操作保留表单。
- 生产 NSIS 回调在隔离文件和测试注册表项中编译执行，覆盖首次选父目录、同名目录、自定义升级路径、旧名称目录、已登记但程序缺失的位置和名称子串。生产卸载清理宏验证升级保留凭据、卸载清除凭据、资料保留和重复清理。
- 打包应用的首次引导、多格式解析、PDF、重复启动、关闭保存和重启通过；0.1.18 → 0.1.19 的隔离应用数据升级通过。公开 GitHub 只读请求正确发现已发布的预发布版。
- 最终 EXE 解出的 36 个文件与受测程序逐字节一致；发行审计核对 12,082 个实际应用／资源文件。ZIP 内 7 项逐项核对，安装器与 ZIP 的 SHA-256 已归档。公开包仅包含三份描述性统计原文，无个人凭据、画像、资料、笔记或学习树状态。

## 复核过程中发现的问题

首轮检查中发现导入期间退出和帮助操作可能打断表单，补齐当前文件保存等待、批次停止和表单保留后重新验证。与打包并行的一次全量检查中，编辑器测试超过原有 60 秒期限；停止资源竞争后，原测试单独通过。之后一次检查被用户中断，没有完整报告，不计入验收。最终检查使用未放宽的原始门槛。

首次 NSIS 构建因替换回调后上游函数未使用而触发严格警告。修正回调引用并恢复用户选择后，隔离执行生产回调验证目录规则。应用载荷未发生变化：复用前核对全部 14,051 个暂存文件哈希，仅允许安装回调和对应测试脚本变更，记录旧基线、当前基线及不变的 ASAR 哈希，再重建安装器。复用证据与最终包审计一同保存，不把复用说成重新编译应用。

重建时进一步发现 electron-builder 仅根据顶层目录时间判断压缩缓存是否可复用，更新资源内的来源清单没有改变顶层时间，导致一份试制 EXE 嵌入旧清单。直接从 EXE 解出清单确认问题后，刷新构建目录时间、重新压缩，并增加最终 EXE 全部文件与受测程序逐字节比对的证据。该试制包不交付；后续重复构建应同时核验实际安装内容，不能仅凭 `win-unpacked` 或日志判定交付成功。

发布前首次远程检查中，Ubuntu 通过；Windows 的一项新增恢复测试直接使用临时目录字符串，未像正式 `FileLibrary` 流程先取得规范路径，因此触发了防重定向校验。修正测试夹具为 `realpath` 后重新执行 CI；不跳过测试、不放宽路径校验，也不改变已验收安装版的应用代码。最终远程结果以对应公开提交的 Actions 记录为准。

## 边界

共享锁采用故障注入，未覆盖真实 OneDrive 的全部同步时序。关键数据持续不可写时不能假装保存成功。传输重试可能遇到供应商已执行但响应丢失的情况，不能保证不重复计费。导入原件成功不代表扫描件正文可解析；当前无 OCR，超出联合资料范围限制仍会明确停止。

本轮未调用真实模型，不新增教学质量或模板效果结论。生产依赖图未改。安装包未签名；NSIS 路径与卸载策略在隔离测试中验证，没有对个人安装或空白 Windows 账号执行完整安装、升级和卸载。本机验收报告记录的是发布前状态；后续公开提交、资产和远程 CI 以 GitHub 记录为准。
