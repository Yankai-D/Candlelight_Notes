# 0.1.16 多格式导入与误触保护复核

代码基线：`d04e49b8dded50276e6a3532bbba07b07756e303`。本轮实现和复核由同一协作者完成，不是独立审计。范围为 DOCX、PPTX、HTML 导入、原件的完整保存链路和导入窗口误触保护。未修改讲述模板，未进行真实模型调用。机器可读结果见 [发布记录](../releases/v0.1.16.json)，格式边界见 [导入说明](../import-formats.md)。

## 交付行为

| 需求 | 实现与验收 |
| --- | --- |
| 更多文件格式 | 新增 DOCX、PPTX、HTML/HTM，提取标题、正文和章节，接入现有笔记生成流程。PPTX 按实际演示顺序读取；常见 Word 数学结构转换为 LaTeX。解析不依赖模型 Key。 |
| 保存原始资料 | 原件按原始字节保存；重新识别、缺失恢复、完整备份与恢复、统一迁移均涵盖新格式。只有 JSON 笔记备份时，不假定原件存在。 |
| 防止误触退出 | 选择文件后，点击框外、Esc 均不退出，关闭图标隐藏，使用底部“取消”。解析错误保留窗口与填写内容；实际读取和保存期间禁用重复操作。 |
| 导入限制可见 | 发现图片、复杂版式等未提取内容时，先显示读取说明，再由用户确认保存。说明随笔记保留。窄屏下操作按钮固定可见。 |

## 验证结果

- `check --require-clean` 的 14 个阶段全部通过：360 项单元／集成测试、10 组浏览器流程及离线 harness 检查；开始与结束源码指纹一致。
- 新增格式测试采用自行构造的中英文资料，覆盖 Word 公式、幻灯片关系顺序、HTML 清理、损坏文件、异常 ZIP 路径、XML 实体、展开限制、Worker 取消、接口鉴权和无 Key 解析。
- 浏览器通过真实接口验证三种格式导入、框外点击、连续 Esc、取消、错误保留、确认前无写入、原件字节与重载持久化；另检查 390px 窄屏布局。
- 最终打包的 Electron 程序成功运行 DOCX、PPTX、HTML 解析 Worker；验证首次引导、单实例、阅读、中文／数学 PDF、退出保存和重复重启。0.1.15 → 0.1.16 的合成笔记和模型设置保留。
- 最终 ASAR／资源逐文件审计 12076 个载荷文件，安装包与 ZIP 摘要匹配。发行包只包含三份允许的 OpenIntro 描述性统计资料及致谢，没有个人资料、画像、笔记或 Key。
- 本轮新增固定版本的生产依赖 `yauzl@3.4.0`。重新执行 `npm audit --omit=dev`，生产依赖已知漏洞数为 0；该结论不包括开发依赖。

测试发现并修复了两项交互问题：窄屏时底部按钮可能被挤出可视范围；仅阻止 React 的 cancel 事件不足以防止连续 Esc 导致原生 dialog 关闭。最终采用固定操作区、原生 `closedby="none"` 与按键保护，并重新运行完整检查。早期失败记录保留在本机证据中，不计作成功验收。

## 边界

DOC/PPT 旧格式需先转换为 DOCX/PPTX；不包含 OCR。图片、图表、动画、复杂排版及部分公式需查看原件；表格单元格按文字顺序读取，不承诺保留表格布局。HTML 不执行脚本或请求外部资源，也不还原网页外观。支持范围不能视为对所有 Office 文档变体的完整兼容保证。

本轮桌面测试使用隔离配置，没有覆盖完整 NSIS 安装／卸载、快捷方式或突然断电。安装包未签名，尚未推送 0.1.16，也未执行该版本的远程 CI；GitHub 已发布的 0.1.15 保持原样。
