# 0.1.9 工程复核

## 范围与基线

请求：复核上次工程收束以来的全部工具改进。基线为本地标签 `v0.1.0`（验收代码 `68cfe7a`），输入版本为 `68bfb22` / 0.1.8。范围冻结在桌面交付、理想树显式重建、品牌与致谢、首次引导、嵌套资料包和多来源独立笔记，以及它们经过的存储、导出与模型边界。此次不扩展产品功能、不更改教学文风、不调用付费模型、不操作个人数据、不推送远程仓库。

## 执行与退出标准

1. 变更清单与风险分析 → 按用户不变量审查代码。
2. 缺陷必须有可复现用例；先记录失败，再修改实现，再运行回归。
3. 锁定依赖的干净检出完成全量 `npm run check`；记录源码、锁文件、环境、各阶段结果及证据指纹。
4. 审计依赖、桌面信任边界与发行内容；验证最终打包程序的启动、保存、重启和退出。
5. 分开给出源码验收、桌面候选包、安装升级、公网发布、教学质量结论；未执行的门禁不得标记通过。
6. 最终报告、缺陷处置、复现命令、回退办法和固定本地版本一并交付。出现 P0/P1 未关闭缺陷则阻止候选包交付。

严重性：P0 为凭据泄露或广泛不可恢复数据损坏；P1 为主要流程失效/来源完整性破坏；P2 为局部功能错误；P3 为可维护性与文档问题。测试通过不能替代语义质量审阅。

### 安全与依赖处置

审计日期 2026-10-19。`npm audit --omit=dev --json` 为零告警；完整 audit 返回 8 个中等级依赖条目，追溯到同一条 `sprintf-js` 精度格式导致拒绝服务的告警 [GHSA-hp3w-g68c-fv3c](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)。公告未列修补版本，npm 建议将 electron-builder 降至 26.5.0，并非安全的小版本修补。

处置 ER-07（P2，构建工具链暂缓）：锁定现有依赖，保留审计记录，不执行自动降级。代码路径核查显示依赖经 electron-builder → @electron/get → global-agent → roarr 引入，global-agent 的日志格式为代码中的固定字符串，外部请求字段作为 context 数据传入。按当前调用路径推断可利用性受限；不将其描述为漏洞不存在。发行审计必须确认这些仅开发依赖不在 ASAR 中。维护者在下一次 Electron/打包工具升级或 2026-11-19 前重新审计；若生产依赖出现该路径、允许外部格式字符串或出现可兼容修补，则重新打开发布门禁。

桌面信任边界复核包括导航/外链白名单、禁用 Node 与危险 Electron fuses、仅回环服务、Origin/Host/会话 token、打印隔离、设置原子替换和退出检查点；自动测试覆盖这些核心边界。这是代码与回归审查，不是第三方渗透测试。

### 兼容与回退

本次不升级 IndexedDB 或笔记备份格式，不改变用户模板和画像。合法旧备份仍可恢复；被 ER-04 拒绝的备份保留原文件，避免将不完整来源静默写入。HTTP 中已被替换字符破坏的旧文字不能自动还原。

### 后续按同一流程交付

在新的干净检出中，准备三份许可与哈希明确的发行素材（见 `desktop/README.md`），然后执行：

```powershell
npm.cmd ci
npm.cmd run check -- --require-clean --out artifacts/check-release
node node_modules/electron/install.js
npm.cmd run package:desktop
node scripts/test-desktop.mjs output/releases/pangzhu-desktop-0.1.9/installer/win-unpacked/PangzhuNotes.exe
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package-download.ps1
node scripts/audit-desktop.mjs --check artifacts/check-release/report.json
```

任一步失败即保留证据、定位并修复；修改运行代码后重新冻结源码验收，禁止把旧版通过记录贴到新版。随后在空白隔离 Windows 用户/虚拟机执行 `scripts/test-desktop-installer.ps1`，补齐安装、重装、卸载及数据保留；跨版本升级另需准备旧版合成资料。公开发布还需负责人处理 ER-07、决定代码许可与签名策略、观察远程 CI，并作出发布决定。
