# 0.1.17 学习任务与练习解答复核

代码基线：`5d32d346b4a9eb39206de13a3a55f378c20e3f2f`。本轮实现和复核由同一协作者完成，不是独立审计。结果见 [发布记录](../releases/v0.1.17.json)，任务边界见 [学习目标与交付成果](../learning-tasks.md)。

## 问题与修正

用户要求练习题的手写过程，但笔记主要解释知识和软件操作。学习目标已传入模型，问题在于旧约束将目标限定为讲解重点，模板又默认按知识依赖重组内容。另一本机核查结论是：所报资料包含外部数据链接与省略的数据预览，未包含完成全部数值题所需的输入；这不能通过强迫模型给答案解决。

修正把交付任务、模板文风、知识画像分开。明确作答时按题号与小问完成推导及结果，默认讲解与纯翻译保持原用途；仅要提示时不揭示答案。公式推导与原文结论区分，题目引用不能冒充答案来源。缺数据时明确缺项，不把待代入公式包装为完整答案。已有笔记、模板快照和个人样稿不自动重写。

同时修复 HTML 导入整体丢弃表单的问题：静态题干、文字选项、列表编号和旧 MathJax 的惰性 TeX 数据保留，不执行脚本或提交表单。该解析问题是独立修复，不把它冒充所报文件的已证实根因。

## 验证

- 最终干净基线的 14 个阶段通过：363 项单元／集成测试、10 组浏览器流程和离线 harness 检查；首尾源码指纹一致。
- 生产生成链路用原创练习覆盖两套模板、题号和公式渲染、原文锚点、纯翻译、局部编辑，以及分段和修复期间的目标保留。
- 使用已配置的 DeepSeek 对原创简单题做两次真实检查，共输出 1699 token。手写任务给出正确的均值与方程解及步骤；提示任务未揭示最终答案；缺少完整回归数据时未编造系数。无对照基线，题量很小，不声称普遍教学优势。
- 私人课程章节的联网复测被自动审批拒绝，因此没有发送该资料；只在本机核查来源和既有笔记。真实调用只包含原创模拟题，不包含用户画像和资料。
- 最终打包程序通过首次启动、隔离窗口、原件解析、PDF、退出保存与重复重启验证；0.1.16 → 0.1.17 的隔离升级保留合成笔记及设置。发行文件隐私与完整性审计通过。

完整回归最初发现旧目标契约的版本断言和冻结提示词需要升级。新增精确的旧／新契约摘要与显式组织规则迁移，不改历史模型消息、响应或成本记录。受限环境中的 Chrome 启动超时使第一轮检查失败并被停止；最终在普通 Windows 环境以隔离数据重新完整运行。最终安装包来自后续冻结基线，先前试构建不作为交付物。

## 限制

当前不自动读取题目依赖的数据链接，也不运行 R/Python。需要完整观测、软件拟合输出或图表时，应先补充这些输入，不能承诺凭截断预览给出可靠数值答案。程序校验不能自动证明数学解答或语义符合目标。

没有新增生产依赖，未重复联网依赖审计；参考 0.1.16 的生产依赖审计。安装包未签名，完整 NSIS 安装／卸载未在本轮执行，尚未上传 0.1.17 或运行该版本的远程 CI。
