# 0.1.14：理想学习树首次进入修复

用户报告首次打开理想学习树显示“输入格式不正确”。在隔离 HTTP 回归中重现：携带当前 `workspaceToken` 的 `list` 请求返回 400，而无标识的旧测试请求可以成功。

## 原因与修复

0.1.13 为防止恢复空间后的旧窗口继续操作，在 `/api/edit` 请求中添加空间标识。服务端验证后仍将该字段传入领域协议，理想树及模板的严格 schema 会拒绝额外字段。此前连接设置问题的修复仅调整了前端路由范围，没有解决 `/api/edit` 内部的协议边界。

本次在 HTTP 入口验证空间标识后消费它，领域输入保持原协议。旧空间标识仍返回 409；未知业务字段仍返回 400。没有放宽 schema、修改画像、重建学习树或调整生产讲述模板。

## 回归覆盖

- HTTP：真实前端格式的目标列表；恢复空间前后有效标识；旧标识拒绝；未知业务字段拒绝。
- HTTP：讲义样稿编辑、模板路由、模板样稿编辑携带空间标识成功。
- 新增真实服务浏览器流程：无 Key 首次进入、空列表、新建入口、刷新读取已有目标、打开与导出、原学习树内容不变。
- 原模拟学习树浏览器流程继续验证复杂布局和模型交互；新流程不模拟本地 API，专门覆盖客户端与服务端的协议衔接。
