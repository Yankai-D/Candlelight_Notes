# 0.1.37 — 恢复进展、增量复查与资料索引 / Recovery progress, incremental review and source indexes

恢复调度按实际失败字段、候选结果和已读取证据判断进展。只更换指令措辞、调整无关字段或重复读取相同内容，不能再次触发已经失败的同一种整份重写。执行器仍可在同一次任务内读取新证据、局部修补或切换策略；检查点保留已尝试状态和被拒绝的候选，避免续接后重新循环。没有增加固定的内容修订次数上限。

Recovery tracks failed fields, candidate values and inspected evidence. Reworded instructions, unrelated edits and repeated reads do not reopen an exhausted whole-response rewrite. The same task can still inspect new evidence, apply a local patch or change strategies. Checkpoints retain attempted states and rejected candidates across resumes. No fixed content-revision quota has been added.

正文首次触发审查时仍提供完整的当前章节。局部修改后的复查和审查意见复核优先提供变更段落、相邻内容、同一知识单元及其原文；原段落编号和证据绑定保持不变。覆盖问题保留完整来源。审查者发现上下文不足时，可在当前任务中请求完整正文和来源，不需用户重试，也不重做正文生成。

The first triggered prose review still receives the full current chapter. Follow-up reviews and finding audits prioritize changed paragraphs, neighbours, the same learning unit and their sources, preserving original indices and evidence bindings. Coverage findings retain all source material. Reviewers can request full context within the current task without a user retry or regenerated draft.

需要章前分析的适应性生成现在按需提取目标无关的原文知识索引，供同一资料库中的其他笔记复用。索引按来源内容、原页码、模型服务身份和索引契约版本绑定；修改原文或切换模型会重新提取。新的学习目标、画像和章节分工仍单独分析，正文写作仍读取完整原文。纯翻译和导入不增加索引调用。

Adaptive generation that requires chapter analysis now extracts goal-independent source indexes on demand for reuse by other notebooks in the same workspace. Indexes are bound to source content, original page numbers, model-provider identity and the index contract version. Source or model changes invalidate reuse. Each new goal, learner profile and chapter role is analyzed afresh, and writing still receives full source text. Translation and import do not add index calls.

索引存放在资料库的 `.candlelight/source-knowledge`，可随资料库迁移和备份；不保存 API Key、用户画像或学习目标。损坏或失效索引重新建立。索引格式恢复停滞时回退到完整原文分析，不能把缓存失败伪装成正文完成。生成记录可查看新建和复用的资料片段数。

Indexes reside in the workspace's `.candlelight/source-knowledge` directory and participate in workspace migration and backup. They contain no API key, learner profile or learning goal. Invalid or corrupt indexes are rebuilt. Stalled index-format recovery falls back to full-source analysis rather than claiming the note is complete. Generation records show newly extracted and reused source groups.

验证覆盖无进展重写、检查点续接、局部修补、复查上下文展开、跨笔记索引复用、失效、并发取消及迁移备份。本轮使用离线故障注入和模拟模型响应，未进行收费模型调用。索引首次提取会增加工作量；上下文字符缩减不等于实际 token、费用或教学质量已得到同等改善，也不保证所有语义上的无效循环都能被识别。

Validation covers stalled rewrites, checkpoint resumes, local patches, review context expansion, cross-notebook index reuse, invalidation, concurrent cancellation, migration and backup. This iteration uses offline fault injection and model doubles without paid model calls. Initial indexing adds work; reduced context characters do not establish equivalent token, cost or teaching-quality gains, nor do these checks detect every semantic form of unproductive repetition.
