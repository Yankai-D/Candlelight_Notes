# 0.1.35 — 收敛修订与生成用量 / Convergent revisions and generation usage

修正复习讲义审查要求删除或合并段落、执行器却只能替换和插入的能力缺口。新增明确的删除与多段合并操作，按候选版本原子提交，拒绝重叠范围、越界修改和删除全部正文；原有来源、数学与知识单元覆盖检查继续执行。纯删除无需额外调用正文模型，执行后仍独立核查效果。

Fixes a capability mismatch in which review requested deletion or merging but the editor could only replace or insert. Explicit deletion and multi-block merging apply atomically to a bound candidate; overlapping targets, out-of-range edits and removal of all prose are rejected. Source, math and learning-unit checks still run. Audited deletion needs no writer call and is independently verified afterward.

复查逐项结算上一轮问题，保留已解决和已驳回意见的记录。未解决问题可换措辞并继续修复，但必须关联原问题；新回归关联实际修改，初审漏掉的事实错误须有来源证据。持续未解的问题提示重新选择操作与目标范围，不恢复固定修订次数额度。意见复核可看到实际改前段落、修改映射与历史决定。

Follow-up review resolves explicit prior obligations and retains settled and dismissed decisions. Unresolved findings remain editable under a stable issue identity. Regressions refer to actual edits, and newly discovered factual defects require evidence. Recurrence changes the repair approach rather than imposing a fixed retry allowance. Advice auditing receives before/after mappings and prior decisions.

局部修订只携带目标、必要邻段和相关原文页，保留原始编号。覆盖缺口保留完整来源；缩减上下文的修复仍可经恢复执行器回到完整上下文。稳定来源前置以利于供应商前缀缓存。生成记录增加分阶段输入、输出、已报告缓存命中与请求耗时；旧记录缺失字段标为未知，不倒推费用。

Local revisions receive targets, adjacent prose and relevant exact source pages with original indices. Coverage issues retain full source, and recovery can expand a reduced context. Stable evidence precedes changing metadata for provider prefix caching. Generation records expose per-stage input/output tokens, reported cache usage and request duration; missing legacy measurements remain unknown and are not turned into cost estimates.

离线回归覆盖删除、合并、冲突、覆盖保护、问题追踪、上下文恢复与用量统计。模拟重复删除流程以四次调用结束（生成、审查、意见复核、复查），合并流程以五次调用结束；这些是协议与调度验证，不是私人整学期任务的真实模型性能结论。整学期资料的持久化知识索引和跨章节并行不属于本次修复。

Offline regressions exercise deletion, merging, conflicts, coverage preservation, issue tracking, context recovery and usage accounting. A synthetic duplicate-deletion workflow finishes in four calls, and a merge workflow in five. These validate protocol and orchestration, not live model performance on a private semester corpus. Persistent corpus knowledge indexes and cross-chapter parallelism are outside this fix.
