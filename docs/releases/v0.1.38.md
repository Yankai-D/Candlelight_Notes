# 0.1.38 — 文件夹列表折叠 / Collapsible folder navigation

资料库左侧默认只展示最外层文件夹和资料包，子层级保持折叠。点击箭头展开或收起下一级，点击名称进入文件夹；展开操作不会改变当前正在查看的资料。没有子文件夹的项目不显示折叠箭头。

The library sidebar initially shows only top-level folders and bundles, with nested levels collapsed. Arrows expand or collapse the next level; names navigate into folders. Expanding a branch does not change the current library selection. Folders without children have no disclosure arrow.

从右侧卡片、面包屑或导入结果进入子文件夹时，导航会展开所需的上级路径，其他分支保持原状。支持键盘操作，深层名称保留省略与完整路径提示。折叠属于界面状态，不改变文件夹结构、资料、笔记或生成流程。

Navigation from a card, breadcrumb or import result reveals the destination's ancestors while leaving other branches unchanged. Disclosure buttons support keyboard input; deep names retain ellipsis and full-path tooltips. Collapse state belongs to the interface and does not alter folders, materials, notes or generation workflows.

浏览器验收覆盖初始折叠、逐层展开、键盘展开、收起、卡片定位，以及嵌套资料包、批量导入和阅读返回。验证使用隔离资料库与模拟模型响应，不调用收费 API。

Browser validation covers initial collapse, one-level disclosure, keyboard expansion, collapsing, card navigation, nested bundles, batch import and returning from reading. Checks use isolated libraries and model doubles without paid API calls.
