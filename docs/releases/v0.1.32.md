# 0.1.32 — 取消隐含恢复额度 / Remove implicit recovery quotas

取消单章三次正文修订、整份笔记共享修订额度，以及执行层调用数、恢复动作数和单阶段动作数上限。联合资料包规划与理想学习树同样不再因累计次数停止。旧记录中的剩余额度不再参与运行判断，调用与修订次数仍保留为统计。

Removes the three-revision chapter ceiling, shared notebook revision allowance, and implicit call, recovery-action and per-stage action limits. Bundle planning and ideal trees no longer stop because of accumulated counts. Legacy allowances no longer control execution; call and revision counts remain statistics.

诊断调查取消四轮上限；新的检查与有效修正可以继续，原样重复的无进展操作仍会转向其他方法或保留状态停止。用户取消、认证失败和原有内容及来源校验继续生效。独立评测显式设置的授权限额仍受执行器约束。

Diagnostic investigation no longer has a four-turn ceiling. New inspections and effective corrections continue; identical operations without progress still trigger alternatives or preserve state and stop. User cancellation, authentication failures and original content/source validators remain effective. Explicitly authorized evaluation limits remain enforceable.

离线回归覆盖十三轮正文修订、四十次同阶段局部修复、八次检查后再执行补丁、超过旧调用上限后的取消，以及旧记录续接。这些测试验证调度行为，不证明真实模型能解决所有错误或保证知识正确；本轮未新增真实 API 调用。

Offline regressions cover thirteen content revisions, forty local corrections within one stage, eight inspections followed by a patch, cancellation beyond the former call ceiling, and legacy continuation. They verify orchestration behavior, not a guarantee that live models resolve every error or produce factually correct content. This change adds no live API calls.
