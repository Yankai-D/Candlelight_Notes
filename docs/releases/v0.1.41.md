# 0.1.41 — 跨章教学安排 / Cross-chapter teaching plan

复习讲义在现有规划中保存全篇学习主线、能力目标、先备关系，以及首次解释、应用和深化的章节职责；贯穿例题可在不同章节承担不同任务。章节分析、写作和异常审查共同使用这些安排。

Revision handouts persist a throughline, learning objectives, prerequisites and chapter responsibilities for introducing, applying and deepening concepts within the existing planning flow. Recurring examples can serve distinct purposes across chapters. Analysis, writing and anomaly review share the plan.

保存的教学记录定位到实际正文，后续章节读取去重摘录。用户编辑、删除正文或修改规划后，不再把旧记录当作“已讲清”；备份恢复保持记录。内部信息不进入阅读正文或导出，也不改变用户画像。

Persisted teaching records point to actual prose and supply deduplicated excerpts to later chapters. Edits, deletions and plan changes invalidate assumptions based on stale records; backups retain the bindings. Internal metadata does not enter reading/export content or change the learner profile.

取消按估算字数触发审查，保留基于具体异常的核查，不新增每章常规审阅调用。旧笔记不自动重写，新讲义及主动重生成使用新安排。新增原创三章流程回归；本轮没有真实模型质量或费用对照，不能将离线测试通过等同于成品质量达标。

Estimated length no longer triggers review. Concrete anomaly checks remain, without another routine review call per chapter. Existing notes are not rewritten automatically; new handouts and explicit regeneration use the new plan. An authored three-chapter orchestration regression is added. No live model quality or cost comparison was run, so passing offline tests does not establish generated teaching quality.
