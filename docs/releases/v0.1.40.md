# 0.1.40 — 精简讲义生成 / Compact handout generation

复习讲义先做知识取舍，再写正文：合并重复定义和同法例题，围绕概念、条件、方法、代表例题与必要变体组织短讲义。新版原创样稿收紧方差推导，保留计算口径及关键依据；论文长文和独立题解继续使用各自模板。

Revision handouts select knowledge before drafting, combining repeated definitions and equivalent examples into compact explanations of concepts, conditions, methods, representative problems and necessary variants. The revised authored sample shortens the variance derivation while retaining calculation conventions and key justification. Narrative papers and exercise solutions keep their own templates.

精简以教学密度为准：小节解决明确问题，短段各有分工，必要的反例与证明保留。同型题合并，有实质条件差异的例子保留；不按字数或单一例题数量机械裁剪。默认不附加完整题库和自测。

Concision is judged by teaching density: each subsection answers a clear question, short paragraphs have distinct jobs, and necessary counterexamples and proofs remain. Merge equivalent exercises while retaining materially different conditions, without mechanical word or example quotas. Full question banks and self-tests are not appended by default.

长章节先分析所有来源分组，再统一选材，按选中知识单元写作，避免逐份翻译后拼接。规划支持本章主讲、前章回顾和不展开内容；省略需保留来源与理由，写作仍使用原始页面。可疑冗余或篇幅膨胀触发现有审查，长度参考不会硬性截断正文或拒绝必要的深入解释。

Long chapters analyze all source batches, consolidate selection, and draft selected knowledge units instead of concatenating batch translations. Plans can specify primary teaching, prerequisite recall and exclusions; omissions retain evidence and reasons, while drafting uses original pages. Suspicious redundancy or expansion triggers the existing review without hard truncation or rejecting justified depth.

精确匹配的旧内置默认模板自动迁移，个人样稿和已生成笔记保留。已有笔记需在“调整并重新生成”中主动重做。离线回归验证流程、定位、异常处理、迁移和取消；原创样稿已检查统一公式渲染。本次未进行真实 API 质量与费用对照，不宣称已证明教学质量或节费改善。

Exact matches to previous built-in defaults migrate automatically; personal samples and existing notes are preserved. Regenerate existing notes explicitly through the goal/revision entry. Offline regressions cover orchestration, evidence, anomaly handling, migration and cancellation; authored previews were checked with the shared math renderer. No live API quality or cost comparison was run, so improved teaching quality or savings are not claimed as proven.
