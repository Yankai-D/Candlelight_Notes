# 0.1.31 — 局部恢复与审查协议 / Local recovery and review protocol

讲义内部覆盖标注允许同一段落同时承担概念、方法、例题或变体用途。标题不能代替正文，标签也不证明事实正确。生成失败时优先诊断当前候选、修正有依据的局部字段；不再为内部标签缺口默认重写整章。

Lecture coverage metadata can assign multiple roles to one paragraph. Headings do not substitute for prose, and tags do not prove factual correctness. Recovery diagnoses the current candidate and prefers supported local edits instead of defaulting to a full rewrite for missing internal labels.

恢复工具增加受摘要、索引和完整锚点约束的数组插入，提供数组条目分页、准确索引及短字段预览。当前候选不再收到旧版本的检查结果。JSON 解析错误提供字符位置与局部原始文本；工具仍不能改变来源、任务或校验器。

The workbench adds atomic array insertion bound to the candidate digest, index and exact anchor, plus item pagination and indexed previews. Observations from obsolete candidates are excluded. JSON parse failures include character offsets and local raw text. Tools still cannot modify sources, tasks or validators.

同一段落上的不同审查意见逐条验证、逐条复核，成立的问题合并成一次段落修订，再逐条映射到新正文复查。错误证据定位列出受影响字段；审查协议恢复先诊断，避免因定位失误重写全部意见。

Independent findings about one paragraph are validated and audited separately. Confirmed findings share one writing operation and retain separate mappings for rechecking. Invalid evidence reports affected fields, and review-protocol recovery starts with diagnosis rather than rewriting every finding after a location error.

首次限额真实测试共 12 次调用：原失败候选在 3 次调用后通过生成校验，25 个正文块的文字保持原样；新生成任务通过生成阶段，但审查阶段仍未完成，故不能报告整章成功。随后依据保存的真实返回修订审查协议，离线回放通过。离线回放与合成测试不是新的模型成功记录，也不构成教学质量评价。实际资料、响应和密钥不随公开源码打包。

The initial capped live test used 12 calls. The saved failing candidate passed generation validation in 3 calls with all 25 prose blocks unchanged. Fresh generation passed its generation stage but did not complete review, so this is not a successful end-to-end chapter result. Subsequent review-protocol fixes passed saved-response replay. Replays and synthetic tests are not new live-model successes or teaching-quality judgments. Private materials, responses and credentials are excluded from public packages.

安装包继承 0.1.30-r3 的安装升级处理。此版本修改项目源码，不覆盖用户的安装目录、原笔记或资料。

The package retains the installer upgrade handling from 0.1.30-r3. Development changes apply to project source, without overwriting the user's installation, notes or materials.

另一次获授权的续测使用 10 次调用，复用已完成分析与生成，但修订因同目标编号与历史意见干扰而未完成。后续修复将已撤销意见隔离出写作任务，提供明确目标清单和字段级诊断，并无损归并同一目标的已确认编号。未改动的真实首份修订返回现已通过协议与渲染回放；两轮真实调用合计 22 次，仍未取得最终整章真实通过记录。

A separately authorized continuation used 10 calls and reused accepted analysis and generation, but revision did not finish because same-target identifiers and historical findings interfered. Subsequent fixes isolate withdrawn advice from the writing task, expose explicit target mappings and field diagnostics, and losslessly bind confirmed aliases to the same target. The unmodified first real revision now passes protocol and rendering replay. The two live runs total 22 calls, without a final successful live chapter result.

工具支持按摘要和完整预期值原子删除候选数组中的多余项目，删除后的索引变化仍受逐项校验约束。保存的真实控制器曾正确提出删除未授权修订，却被旧工具拒绝；该原始操作现已通过回放，并通过原修订与渲染校验，不需要重写正文。删除必需修订仍会被覆盖校验拒绝。

Tools can atomically remove excess candidate-array entries using the digest and exact expected value; subsequent operations still validate shifted indices. A saved real controller correctly proposed removing an unauthorized edit, but the old tool rejected it. That unmodified operation now passes replay and the original revision/rendering validators without rewriting prose. Removing a required revision still fails coverage validation.

人工检查还发现真实审查把等价的排序阈值规则错误地判为不等价，且复核没有拦住。因此机械恢复通过不能称为知识正确性通过。复核上下文新增定义代入与反例检验要求，这项提示约束尚未取得新的真实验证，不构成数学可靠性的保证。本版本应保留此已知限制，不把检查通过解读为所有生成质量问题已经解决。

Manual inspection also found a false claim that equivalent ordered-threshold rules were different, which the auditor failed to reject. Mechanical recovery therefore does not certify factual correctness. Audit context now requests substitution of definitions and verification of claimed counterexamples; this prompt constraint has not received new live validation and is not a mathematical guarantee. Engineering checks must not be read as resolving every generation-quality issue.
