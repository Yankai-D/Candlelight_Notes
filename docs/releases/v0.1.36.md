# 0.1.36 — 降低恢复开销 / Lower recovery overhead

修复大型联合资料笔记中，小字段错误仍反复携带完整来源、正文与调查历史的问题。恢复器先接收精确出错位置、相关字段与上下文索引，完整资料留在本地按需读取；正在调查的上下文窗口与重复校验约束去重，检查点保留原始依据。大型任务出现准确字段诊断时优先局部修补，整段重写仍可按实际需要使用，不增加固定重试额度。

Fixes excessive recovery input in large bundle notes, where small field errors repeatedly resent full sources, prose and investigation history. Recovery starts with precise failures, relevant fields and context indexes; complete inputs remain locally available to read on demand. Active investigation context and repeated expectations are deduplicated while checkpoints retain evidence. Large tasks with exact field diagnostics prefer local patches; rewriting remains available without introducing a fixed retry quota.

章节分析、正文审查和意见复核使用请求内的短证据编号，返回后恢复成原有内容绑定编号，再执行来源与正文校验。未知编号、失效来源和冲突引文仍拒绝；JSON 修复后也执行同样的编号恢复。审查模型只提供结论与具体问题，冗余的四项状态表由程序生成，旧版显式状态矛盾仍会报告。复查与意见复核的错误包含准确路径与需要核对的关联，减少猜测性调查。

Chapter analysis, note review and advice auditing use short request-local evidence labels. Responses are mapped back to content-bound references before source and prose validation. Unknown labels, stale sources and contradictory quotes remain invalid, including after JSON syntax repair. Review returns its verdict and concrete findings; the host derives redundant status labels while still rejecting contradictory legacy states. Follow-up and audit errors identify exact fields and related obligations to reduce speculative investigation.

新增离线测试覆盖大型上下文的局部修复、长期调查窗口、旧观察再次读取、短编号与损坏 JSON 的恢复、旧证据拒绝、审查一致性和重复约束去重。本轮未进行真实模型调用；离线上下文体积减少不等于费用、延迟或内容质量已经得到真实模型验证。

New offline tests cover local repair with large inputs, long investigations, rereading earlier observations, short references and malformed JSON, stale-evidence rejection, review consistency and expectation deduplication. This release used no live model calls. Reduced offline context size is not proof of billed savings, latency improvements or live content quality.
