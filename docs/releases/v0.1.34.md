# 0.1.34 — 长任务连接修复 / Long-running local requests

修复桌面版内部请求等待约五分钟后被取消的问题。此前桌面协议通过 Node fetch 等待整章结果，触发响应头超时后返回纯文本，前端又按 JSON 解析，显示 `Unexpected token 'L'`。现在使用仅连接当前本机服务的 HTTP 流，保留建立连接的超时与用户取消，不对整段生成、审查和修订设置总时限，也不自动重放可能已执行的 POST 请求。

Fix desktop requests being cancelled after roughly five minutes. The custom protocol previously waited for a complete chapter through Node fetch; its response-header timeout returned plain text that the client then parsed as JSON, producing `Unexpected token 'L'`. The bridge now uses an HTTP stream confined to the current loopback service, retaining connection establishment timeouts and user cancellation without a whole-task deadline or automatic replay of potentially executed POST requests.

移除服务端生成、规划与自动整理的整段固定超时，保留连接测试的短时限、供应商请求的网络错误处理、退出暂停和已有检查点机制。真实连接中断与非法本地响应有独立错误分类，前端不会把它们当模型 JSON 格式错误，也不会继续切到其他章节重复调用。已完成章节保留，继续生成使用已有任务进度与适配的阶段检查点。

Remove fixed whole-task deadlines for generation, planning and organization. Connection probes retain their short deadline, while provider network handling, shutdown cancellation and checkpointing remain in place. Actual local disconnections and invalid local responses receive distinct classifications, preventing model-format misdiagnosis and cascading calls to subsequent chapters. Completed chapters remain intact; continuation uses task progress and compatible stage checkpoints.

新增本机传输回归，覆盖延迟响应头、延迟正文、取消、二进制原文、权限边界、连接拒绝、响应中断及章节续接。`node scripts/test-long-local-generation.mjs` 另外运行超过六分钟的真实时长测试，以本机模拟模型完成生成和审查，并同时复现旧 fetch 的五分钟超时；不发送个人资料，不调用外部模型。安装版通过新安装包更新，不改动用户安装目录中的源码。

Local transport regressions cover delayed headers and bodies, cancellation, binary sources, origin boundaries, refused connections, interrupted responses and chapter continuation. `node scripts/test-long-local-generation.mjs` additionally runs a real-time test exceeding six minutes with a local mock provider for generation and review, alongside reproduction of the old fetch timeout. It sends no private materials and calls no external models. Installed copies are updated through the installer rather than by editing their source in place.
