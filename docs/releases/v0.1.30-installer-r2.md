# 0.1.30 · installer revision 2

修正安装器反复提示应用未关闭的问题。原打包器用进程路径的目录前缀判断运行状态，会把安装包自身、同目录其他程序及名称前缀相同的相邻目录也算进去。现在通过 Windows 原生进程枚举与完整可执行文件路径，只检测目标安装目录的 PangzhuNotes.exe；不依赖 PowerShell 策略或按名称强制结束进程。无法读取进程身份时明确报告核验失败，不把它说成应用仍在运行。

Fixes repeated false “application is running” prompts. The upstream directory-prefix predicate could include Setup itself, unrelated executables and prefix-sharing sibling directories. Native Windows process enumeration and full executable paths now identify only PangzhuNotes.exe in the target installation. The guard does not depend on PowerShell policy or force-kill processes by name. Unreadable process identity is reported as an inspection failure rather than a confirmed running app.

旧版卸载器仍含原有判断，因此从旧安装目录内启动更新时，安装器先复制到现有更新缓存，退出原进程，缓存中的安装器等待原进程退出后继续。保留 /S 和已被 NSIS 解析的 /D 参数；不改写用户安装目录中的源码。真正仍在运行的目标程序会得到短暂退出时间，然后提示具体路径和 PID，由用户保存并退出。

Older uninstallers retain the legacy predicate. When launched below the old installation prefix, Setup hands off to the existing updater cache, exits its original process and waits for that process to exit before continuing. Silent mode and NSIS’s already-consumed destination argument are preserved. Installed application source is not patched. A genuinely running target receives a short exit grace period, then a path/PID-specific prompt to save and close.

验证使用实际编译的 NSIS 钩子、临时进程和唯一测试注册表键，覆盖安装器自身、无关进程、其他安装、中文与特殊字符路径、32 位安装器识别 64 位进程、关闭后继续、卸载侧检查和旧版升级交接。运行 `npm run test:installer:process`，需 Windows 与已缓存的 NSIS 工具。安装路径和凭据删除策略另行回归。

Verification compiles the production NSIS hooks and exercises live temporary processes with a unique test registry key. Cases cover Setup itself, unrelated processes, separate installations, Unicode/special-character paths, 32-bit detection of 64-bit processes, continuation after close, uninstall-side checks and legacy handoff. Run `npm run test:installer:process` on Windows with the NSIS tools cached. Directory selection and credential-removal policies are tested separately.

这是安装器修订，应用版本仍为 0.1.30。复用此前已验收应用的逐字节一致文件，重新封装安装器，并再次解包比对。此前的应用测试不代表本次执行了完整的个人安装、重装与卸载；本轮不会更改用户的安装注册信息、快捷方式或真实资料。

This is an installer revision; the application remains version 0.1.30. The installer is rebuilt over byte-identical, previously verified application files and extracted again for comparison. Earlier application checks do not imply that a complete personal install/reinstall/uninstall was run in this review. Personal installation registration, shortcuts and real materials remain untouched.
