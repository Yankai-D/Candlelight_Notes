# 0.1.30

讲义整理按概念与适用条件、方法流程、代表性来源例题、课内变体组织，合并重复材料。联合资料的章节分析记录知识单元和合并依据，生成与审查使用同一约定。单篇讲义使用精简模板；明确的逐题解答、纯翻译和论文长文仍遵守各自的任务要求。个人样稿与既有笔记保留，完整重组通过“调整并重新生成”进行。

Lecture synthesis organizes concepts and conditions, procedures, representative source exercises and course variations, merging duplicates. Bundle chapter analysis records learning units and merge evidence, shared by writing and review. Single-source lectures use the concise template. Explicit exercise solving, translation and narrative papers retain their own contracts. Personal samples and existing notes are preserved; full restructuring uses the adjust-and-regenerate action.

审查意见可以通过 `refine` 收窄：保留真实缺陷、撤回错误批评，在原目标内给出修法，再复查正文。恢复工具区分待修复返回值与正文快照的绑定，支持读取完整只读上下文。首次调用获得实际输出契约，新版笔记的输出说明不再包含它所禁止的旧分区字段。

Audit can narrow a finding with `refine`, retaining real defects while withdrawing invalid criticism, repairing the original target and rechecking prose. Recovery tools distinguish response bindings from prose-snapshot bindings and expose read-only context. First calls receive actual output contracts; modern note schemas no longer advertise forbidden legacy section fields.

受限真实验证用了 7 次调用：混合意见一次复核收窄成功；同章生成遇到 JSON 语法错误及方法步骤覆盖不足，在同一任务内恢复后通过触发式正文审查。原笔记没有修改。这是一项具体恢复案例，既不证明关闭纠错时首轮都成功，也不证明讲义教学质量；测试沿用旧章节规划，新规划风格还需要内容审阅。原始资料与调用保存在本机，不随源码发布。

A bounded live test used 7 calls: audit narrowed the mixed finding on its first call; chapter generation recovered from invalid JSON and omitted method coverage within the same task, then passed triggered prose review. Original notes were unchanged. This is a specific recovery case, not proof of error-free first attempts or teaching quality. It retained the old outline; the new planning style still needs content review. Private sources and raw calls remain local and are not distributed.

工程回归覆盖关闭恢复时的有效流程、遗漏内容、伪造来源、非法合并、混合意见的修订边界，以及默认模板升级时对个人样稿和撤销记录的保留。历史实验原始记录不改写；新讲义实验提示另行固定。DOM 编辑器测试直接转译真实前端源码，避免开发服务器加载超时；生产构建与真实浏览器测试仍单独执行。

Regressions cover valid flows with recovery disabled, omitted content, fabricated sources, invalid merges, mixed-finding edit boundaries and preservation of personal samples and undo history during default-template upgrades. Historical experiment traces remain unchanged; current lecture prompts are separately pinned. DOM editor tests transpile real application source without development-server startup; production builds and real-browser suites remain separate checks.
