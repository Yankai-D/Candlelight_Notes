# 0.1.39 — 生成进度与回归报告 / Generation progress and regression reports

笔记生成与局部 AI 编辑增加可折叠进度面板：阶段、耗时、调用次数、已完成章节、分阶段 token 和修复动作。状态接口失败不会重发生成请求；暂停沿用现有检查点，未报告用量保持未知。默认收起，避免占用阅读空间。

Notebook generation and inline AI editing gain a collapsible panel for stages, elapsed time, calls, completed chapters, stage tokens and recovery actions. Status failures never replay generation. Pausing preserves the existing checkpoint behavior, and unreported usage remains unknown. The panel starts collapsed to preserve reading space.

新增 `eval:regression`，基于冻结运行和人工工作册比较内容评分、失败、token、耗时及可选价格估算。严格核对配对条件与记录哈希，失败样本不剔除，缺少评分或用量不冒充通过。离线模拟加入完整工程检查，未进行收费模型调用；这些报告阈值不限制产品生成。

The new `eval:regression` compares content ratings, failures, tokens, latency and optional cost estimates using frozen runs and human workbooks. It checks pairing conditions and artifact hashes, retains failures, and refuses to treat missing ratings or usage as passing evidence. Offline simulation joins the complete engineering checks without paid model calls; these reporting thresholds do not limit product generation.

验证包括 HTTP 真实接口与本地模型替身、轮询失败不重试、用量累加、取消清理、三种主题及窄屏布局、回归报告拒绝错误配对与错误质量结论。范围和复现入口见 [生成观察与回归说明](../generation-observability.md)。

Validation covers real local HTTP endpoints with a model double, non-replaying status failures, usage aggregation, cancellation cleanup, three themes and narrow layouts, and rejection of invalid pairings or unsupported quality conclusions. See [observability and regression documentation](../generation-observability.md) for scope and reproduction.
