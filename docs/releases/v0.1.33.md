# 0.1.33 — 阅读侧栏、大资料与讲义风格 / Reader layout, larger sources and handout style

复习讲义默认样稿与写作契约重置：按完整知识主题组织章节，将原理、方法和例题放在同一知识脉络中，减少碎片章节和重复铺垫。取消正文三段以上必须另设标题的规则。规划与异常触发审查使用同一编辑标准，保留个人样稿及已有笔记。新增三类原创风格样稿和离线回归；真实模型生成质量尚未完成对照评测。

The default revision-handout sample and writing contract now group complete knowledge topics, integrating reasoning, methods and examples while reducing fragmented chapters and repetition. Prose no longer requires an extra heading merely because it has three paragraphs. Planning and anomaly-triggered review share the editorial standard, while personal samples and existing notes remain intact. Three authored style anchors and offline regressions are included; a live comparison of generated quality has not yet been completed.

资料页数上限统一提高到 2000 页，涵盖 PDF、课件、资料包来源快照、笔记保存与恢复、模型请求及学习树资料下载。大文件超过 300 个阅读分段时合并相邻分段，保留全部来源页及其顺序；正文生成继续按上下文分批。

The source-page limit is now 2,000 across PDFs, slides, bundle snapshots, note storage and restoration, model requests and learning-tree downloads. When a large file produces more than 300 reading sections, adjacent sections are grouped without dropping or reordering source pages. Generation continues in context-sized segments.

阅读侧栏明确约束内层网格宽度。长章节名和资料名不会再撑宽正在阅读、阅读路线与原文对照模块；侧栏名称省略显示并可悬停查看，正文长标题自动换行。

The reader sidebar now constrains its internal grid width. Long chapter and source names no longer stretch the reading overview, route or source preview. Sidebar titles truncate with hover text, while long article headings wrap.

理想学习树的重建入口不再被导出、下载或论文查找共用的忙碌状态锁住。提交前核对最新来源版本，论文查找可在重建窗口中暂停。调整建议和原因可留空，按原目标生成新版本并保留旧版本；响应中断后的重复提交沿用同一请求编号。

The ideal-tree rebuild entry is independent of the shared busy state used by exports, downloads and paper searches. Submission checks the current source revision; paper research can be paused from the rebuild dialog. Feedback is optional: rebuilding can reuse the original goal while preserving the previous edition. Retries after a lost response retain the same request identity.

本次验证使用自制资料与离线模型替身，不发送个人资料，也不新增真实模型调用。安装包仅附带原有描述性统计示例，不包含个人画像、笔记或 API Key。安装版通过新安装包更新，不直接修改用户安装目录中的源码。

Verification uses authored fixtures and offline model stubs, with no private material sent and no new live model calls. The installer includes only the existing descriptive-statistics examples, without personal profiles, notes or API keys. Installed copies are updated through the installer rather than by editing their source files in place.
