# 学习空间的备份与恢复

入口：设置 → 资料存储 → 资料备份与恢复。资料列表的“…”提供“仅移除记录”和“移入回收站”。两者均保留原位置文件，可在维护界面找回；只有回收站二次确认的永久删除才删除应用管理的笔记、原文副本及本空间的生成记录。其他安装版本若关联相同文件，也会失去这些文件。独立备份和其他笔记已冻结的来源摘录不被追溯删除。

完整备份创建独立文件夹，保存各阅读版本、纸条、修改历史、可取得的原文、画像、模板、分类、资料树数据、理想学习树与已下载节点资料、生成记录和移除记录。连接 Key、模型设置、阅读启动方式不进入备份；恢复沿用当前安装的连接与启动设置。备份完成后可自行压缩和复制。单文件上限 128 MB，总量 4 GB，最多 10000 文件、2000 条资料及移除记录；超过限制会停止并保留原库。缺失文件单列提示。

恢复先检查清单、路径、大小与 SHA-256，预览后明确确认；确认时再次校验。只复制到新建目录，不覆盖旧笔记。完成后切换轻量索引及偏好，保留返回上个空间的入口。应用内恢复期间阻止其他写入与生成；旧窗口携带的空间标记会被拒绝，需要刷新。索引与偏好使用本机恢复日志，进程中断后下次启动补完。散列校验检验文件完整性，不是作者签名或备份来源认证。

备份目录以及未完成复制的目录不会被自动识别成另一套笔记。失败产生的目录有 `.candlelight-incomplete` 标志，可在确认本次恢复没有成功切换后自行清理。成功恢复的目录使用 `.candlelight-space` 标志，旧空间扫描父目录时不会混入它；手动明确选择这个目录仍可识别。不要同时在多个应用进程内对共享目录进行整库维护；当前只协调同一服务内的请求，并以单文件锁保护笔记，未提供跨进程的整库事务。

原文缺失时，“重新选择原文”复制用户选定的文件，不重做分析或生成。用户负责选择与笔记匹配的原文，程序验证文件类型并拒绝覆盖已有原文。保存冲突时，“处理保存冲突”对照正文节选：可保留当前完整修改为新笔记，或确认使用磁盘版本。预览本身不会使旧窗口重新获得覆盖权。

生成记录保存在资料系统目录 `.candlelight/generation-records/`，完成后按每资料最近 20 次、64 MB 回收；正在执行的记录暂不回收。单记录最多 32 MB，超过时压缩重复请求正文为摘要，原始请求快照仍保留。运行未结束的记录明确显示未记录结束状态，不猜测已经成功。备份/恢复不调用模型。

程序、个人连接配置和资料目录的分离约定见 [工程说明](engineering.md)。卸载 Key 清理规则保持不变，生成记录属于资料目录的学习内容。工作空间备份不是同步、不是版本合并，也不提供网络盘或断电耐久性的已验证保证。
