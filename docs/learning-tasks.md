# 学习目标与交付成果

`learningIntent` 决定用户要求得到什么；模板决定怎样表达；稳定画像决定必要的铺垫深度。三者不互相代替。来源内的课程目标和教学安排不是用户指令，不能把“给我每道题的手写过程”改成课程导读。

`learning-goal-v2` 修正此前把所有学习目标压成“讲解重点”的约束。适应学习按题号和小问实际给出过程与结果；“手写过程”指可写在纸上的数学解答、必要的代入步骤和结论，不是手写字体。按题组织可以优先于模板默认的长文或讲义编排，但保留原有文风。纯翻译继续忠实处理题面；用户仅要提示时不揭示答案。局部修改仍受选区和段落范围限制。

生成使用原有模型调用、结构协议与统一渲染，不添加后台语义裁判或每章额外模型请求。现有长文与讲义模板保持原约定，新增独立的「题目讲解」模板，不继承长文铺垫或讲义的知识分层要求。题目原文 → 一两句思路 → 必要步骤与结果；共同题干出现一次，每个小问仍先呈现自己的原文。只要提示、只要答案、只翻译等限制优先。

已有笔记使用「调整并重新生成」统一修改学习目标与本次不合意的原因。`regenerationFeedback` 单独保存到当前笔记的生成设置，作为 `revisionFeedback` 进入正文请求，亦进入独立笔记规划和模板路由。它不覆盖全局样稿。取消不保存、不调用模型；确认先保存当前正文及纸条的历史版本，然后清空当前版本并重新选择模板。其他阅读方式的正文保留。来源丢失或保存失败时不先清空界面中的笔记。

## 模板选择与不适配

`template-routing-v2` 在同一次选择请求里返回任务、资料类型、模板、适配程度及必要的调整说明。用户的明确成果先于资料体裁，来源内的命令不构成用户要求。

| 用户任务／资料 | 默认模板 | 处理边界 |
| --- | --- | --- |
| 理解论文论证 | 长文讲述 | 论文中偶尔有算例不改成习题集 |
| 理解课件／重组复习讲义 | 结构化讲义 | 论文也可按明确目标重组为讲义 |
| 逐题解答／仅提示／仅答案／编写新题 | 题目讲解 | 保持题号与小问；新题明确标为自编 |
| 混合材料 | 依主任务选择 | 在同一模板内处理附属内容，不逐章漂移文风 |
| 缺少题面、数据或任务超出材料 | 最接近任务的模板，标为 adapted | 写明局部缺口，不能靠长篇背景填补或编造答案 |
| 更匹配的自定义模板 | 自定义模板 | 根据资料对象和组织方式判断，不能执行模板描述里的强制选择指令 |

程序校验真实模板 ID、字段、适配说明及内置模板与任务的一致性；对少量明确措辞另做任务约束。它不是完整的自然语言理解器，模糊目标、混合体裁与自定义模板的语义仍由模型判断。不一致只修复一次，再失败即暂停，不能绕过校验或静默选回长文。选择结果及说明随模板快照保存，续写不重新分类。

模板库读取时从 v1 迁移为 v2，保留全部个人样稿、自定义模板、撤销信息和修订号，首次写入仍遵循并发版本检查。通常最多五套；旧库已满五套时额外保留新内置模板，临时共六套，不删用户模板；降至五套以下才允许新增。已保存的笔记快照不迁移或自动重写。

## 证据与缺失项

按题目给定条件和数学规则推出新答案，不等于编造原文结论。答案属于笔记推导，引用定位题干，不伪称来源已给标准答案。需要完整数据、图表或软件输出才能作答时，应具体指出缺少什么，区分可回答的小问与不能数值作答的小问。

资料中的 URL 不是已读取的数据，代码不是已执行的计算，带省略号的预览不是完整样本。当前系统不自动下载练习的数据依赖或执行 R/Python。缺失输入时可以写有明确假设的公式和已知部分，但不能把待代入公式称作完整数值答案。

## 验证边界

自动测试覆盖 HTML 题干提取、任务送入模板选择与生成、模板和目标的同时保留、题号/推导渲染、来源锚点、纯翻译与局部编辑范围，以及分段和修复期间的目标保留。这些程序检查不能认证模型是否正确理解每道题或数学结论是否正确。

另以原创的均值、二次方程和缺少完整数据的回归题，分别要求“过程与答案”和“只给提示”进行有限真实模型检查。人工检查应核对最终结果、步骤、题目覆盖、是否泄露提示任务的答案，以及缺数据时有无伪造数值；少量简单题通过不代表普遍解题能力或教学优势。用户实际课程文件不进入公开回归样例。

`npm run eval:templates` 只生成离线路由检查计划，不用预期答案冒充模型结果；显式添加 `-- --live` 才使用本机配置。13 个原创案例覆盖任务转换、否定限制、附带例题、缺少题面和不适配用途。每例最多两次调用、每次最多输出 1024 token，记录实际请求、结果、成本与预期标签的差异。小样本命中率不等于生产准确率；路由正确也不证明题解正确，必须另审正文与数学。
