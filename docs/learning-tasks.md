# 学习目标与交付成果

`learningIntent` 决定用户要求得到什么；模板决定怎样表达；稳定画像决定必要的铺垫深度。三者不互相代替。来源内的课程目标和教学安排不是用户指令，不能把“给我每道题的手写过程”改成课程导读。

`learning-goal-v2` 修正此前把所有学习目标压成“讲解重点”的约束。适应学习按题号和小问实际给出过程与结果；“手写过程”指可写在纸上的数学解答、必要的代入步骤和结论，不是手写字体。按题组织可以优先于模板默认的长文或讲义编排，但保留原有文风。纯翻译继续忠实处理题面；用户仅要提示时不揭示答案。局部修改仍受选区和段落范围限制。

生成使用原有模型调用、结构协议与统一渲染，不添加后台语义裁判或每章额外模型请求。模板选择继续在已有目录中选择；两套内置模板的存储结构、个人样稿和历史笔记不变。已生成的笔记不会因更新规则自动改变，需要用户选择重新生成。

## 证据与缺失项

按题目给定条件和数学规则推出新答案，不等于编造原文结论。答案属于笔记推导，引用定位题干，不伪称来源已给标准答案。需要完整数据、图表或软件输出才能作答时，应具体指出缺少什么，区分可回答的小问与不能数值作答的小问。

资料中的 URL 不是已读取的数据，代码不是已执行的计算，带省略号的预览不是完整样本。当前系统不自动下载练习的数据依赖或执行 R/Python。缺失输入时可以写有明确假设的公式和已知部分，但不能把待代入公式称作完整数值答案。

## 验证边界

自动测试覆盖 HTML 题干提取、任务送入模板选择与生成、模板和目标的同时保留、题号/推导渲染、来源锚点、纯翻译与局部编辑范围，以及分段和修复期间的目标保留。这些程序检查不能认证模型是否正确理解每道题或数学结论是否正确。

另以原创的均值、二次方程和缺少完整数据的回归题，分别要求“过程与答案”和“只给提示”进行有限真实模型检查。人工检查应核对最终结果、步骤、题目覆盖、是否泄露提示任务的答案，以及缺数据时有无伪造数值；少量简单题通过不代表普遍解题能力或教学优势。用户实际课程文件不进入公开回归样例。
