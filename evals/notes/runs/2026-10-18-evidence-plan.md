# 证据强度与背景假设：调用前约定

依据 [三场景实际结果](2026-10-18-product/README.md)，本轮只修改适应讲解中的一个共同写作契约：保持来源的论证强度，在教学补充依赖额外设定时就近说明条件，同时保留已经成立的定义、推导与必要解释。

实现为 `shared/adaptive-evidence.mjs` 的 `adaptive-evidence-v1`。它附加到笔记生成、纸条、局部改写和风格编辑的 system 指令，长章节各片段沿用；不修改用户模板、画像或已有笔记，不用于纯翻译，不增加模型调用或新的输出字段。它是写作要求，结构校验器不会因此获得语义认证能力。数学自动复核保持冻结。

## 比较与预算

复用 ResNet §3.1、OpenIntro 分类数据和 ResNet 小纸条，固定之前的来源、画像、目标与模板。两组均使用完整生产 harness 与相同修复路径：

- `previous-harness`：仅去掉新契约。其初始消息必须逐项等于上一轮归档的真实 harness 提示，测试不等则停止。
- `harness`：同样消息末尾增加新契约。其他消息、样稿与预算完全相同。

每组每场景一次，共 6 个候选。每个最多 2 次请求，每次最多 4096 输出 token，累计最多 8192；总计最多 12 次请求、49152 输出 token，输入另计。一次运行后停止，保留失败、修复和全部原始响应。不用上一轮输出代替本轮对照组，不挑选最佳输出，不自动模型打分。

## 调用前确定的核对项目

| 场景 | 重点 | 反向检查 |
| --- | --- | --- |
| ResNet 长文 | 是否保持“提示／可能”的强度；明确观察、假设与证明的区别 | 不把残差定义、同维条件或公式关系说成不可确定；不删除恒等映射与优化难度的解释 |
| ResNet 小纸条 | 是否直接回应追问；若引入初始化等额外机制，有没有说明条件和来源边界 | 不只剩“不能保证”的空泛回答；不重讲整章，不把已有笔记当成证据 |
| OpenIntro 课件 | 定义、图形区别、群体内分母和原有数值是否完整、清楚 | 不因强调证据而把比例计算变成猜测，不加机械免责声明或改成连续长文 |

核对以全文及确切段落为依据，不能用某个词是否出现、字数长短或格式接受率代替。验收要点仅供审阅，不发送给模型。AI 初步观察与独立人工评分分开；人工表单保持空白。

该写作约束属于生产要求的具体化，不声称获得质量优势。若本轮出现明确的内容遗漏、歪曲已知事实或范围退化，优先撤回并保留实验记录；不能为了让实验显得成功而调整合格线。细微风格取舍等待用户反馈，不能由开发代理代替独立评审。

## 执行

```sh
npm run eval:notes -- --suite evidence-boundary --demo
npm run eval:notes -- --suite evidence-boundary --live --case resnet-residual --case openintro-categorical --case resnet-inline
```

沿用现有冻结计划、预算、检查点、匿名审阅、失败分母与零调用重放，不创建新的评测服务。三个案例均为已见开发材料，其中两个共享来源。此轮不检验留出泛化、全文衔接、模板路由、跨画像稳定性或用户学习效果。
