# 主张级协议 v1 / v2 对照计划

日期：2026-10-18（用户时区）。此计划、案例、判据和实现须在真实调用前提交；本轮不根据新结果调提示或补跑。

## 目的

检验将段落级判断改成有定位的多主张、显式前提与证据类型后，是否仍能保留正确内容、识别漏条件并提出局部候选。旧 8 例仅作离线回归，新真实比较使用 4 份原创开发稿；两版看到相同来源、笔记及目标。

| 案例 | 参考标签 | 判据 |
| --- | --- | --- |
| matrix-overclaim | issue | 元素全非零不保证矩阵可逆；1,2,2,4 的行列式为零 |
| matrix-valid | no-issue-found | 可逆当且仅当行列式非零；保留正确充要条件 |
| normalization-valid | no-issue-found | 正缩放同向，负缩放反向 |
| normalization-overclaim | issue | 非零缩放不能保证同向；v=2,a=-1 的两个归一化结果为 -1 和 1 |

每份稿运行原 v1 和新 v2，共 8 个候选；按案例轮换两版请求顺序。每版每例一次，不重复。v2 默认禁止撤回无依据保证；该路径单独做离线执行验收。本轮新材料不测试缺附录的真实分类，不能对此作改进结论。

## 控制与预算

使用本机已配置的 `deepseek-flash`，temperature=0，JSON 模式，thinking disabled。两版实际每例最多 2 次请求、每次最多 2,048 输出 tokens、总计 4,096。全轮最多 **16 次调用 / 32,768 输出 tokens**，另计输入。没有裁判 API 或额外搜索。模型诊断需要第二次截断重试时，会占用修订名额。

v2 增加文字单元及前提结构，输入输出更长，这是协议代价，须按实际发送的请求统计。不能将差异全归于提示词，也不能声称是在相同输入 token 条件下提升。
