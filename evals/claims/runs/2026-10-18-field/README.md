# 实际教材讲义：完整复核通过执行校验，仍发现内容漏检

本轮从 OpenIntro 公开教材均值选段生成一份新讲义，用固定的简化协议复核全部内容。11 个正文块、39 个文字单元分成六批，全部获得合法诊断；模型返回 38 个 retain 和一个 needs-source。这个分布不代表讲义有 38 句正确。

AI 初步核对发现：讲义把算术均值描述成“观测值以自身大小为权重”，复核器没有指出；对均值受极端值影响的相近表述，它一处保留、一处要求补来源。短探针上的表现未直接转化为实际讲义的可靠复核。因此继续保持实验状态。

## 保留的发现

`b7:s2` 写“各观测值以自身大小为权重、以观测个数为分母”。算术均值的各项系数应相同；“贡献大小”与“权重”混用会误导计算。对数据 1、3，算术均值为 2；按自身作权重再除以观测数会得到 5，按权重和归一化则为 2.5。复核器在该句返回 retain。这是对本句的 AI 初步分析，不将数值回归宣传为通用中文判错器。

`b7:s3` 的“极端值会拉动均值”被保留，`b11:s5` 的相近表述被要求补来源。给定均值定义、固定样本数和其他观测，修改单个观测的影响可直接写成 delta/n。尚需独立审阅判断这种保留／缺来源分歧是否属于过度谨慎；不能声称只要引用存在就必须接受补充推导，也不能把相近句子的差异直接归因于窗口策略。

完整证据见 [findings.json](findings.json)。它是 `provisional-ai-review`，与空白人工记录分开；没有填入人工参考答案，没有按事后发现回改本轮输出。

## 人工工作册与复现

```sh
npm run eval:field -- --inspect evals/claims/runs/2026-10-18-field/run.json --out artifacts/field-review/2026-10-18-replay
```

零调用生成 `review.html`。审阅者先读完整来源和讲义，再逐句记录判断及依据，随后才展开模型意见；展开前和展开后的判断分别保存。若已经读过本说明或这次对话中的诊断，应如实标记此前接触，不能自称保持盲态。未接触材料的同学或领域审阅者可以另外保存首次记录。

```sh
npm run eval:field -- --summarize evals/claims/runs/2026-10-18-field/run.json --review path/to/field-review.json --out artifacts/field-review/my-summary
```

汇总保留逐句错位、可能漏检／误报和未完成项，不计算独立准确率。实际人工判断仍为空，状态为 awaiting-human-review。工具交付不等于独立人工审阅完成。
