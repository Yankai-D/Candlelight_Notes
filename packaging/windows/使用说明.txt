烛光笔记 Candlelight · Windows 64 位便携包
Candlelight Notes

开始使用
1. 将 ZIP 完整解压到有写入权限的目录，例如 D:\Apps\PangzhuNotes。不要在压缩包内直接运行。
2. 双击 Start.cmd（启动）。程序会打开一个独立的 Edge / Chrome 阅读窗口。
3. 若需要 AI 整理，在“设置 → 模型连接”中填写自己的 API Key 并保存。
   未设置 Key 时仍可查看资料库、原文及模板样稿；本包不预置生成好的全文笔记。
4. 用完先关闭阅读窗口，再双击 Stop.cmd（停止服务）。只关闭窗口不会停止后台生成。

环境
适用于 Windows 10 / 11 x64，已内置 Node.js 24.14.1，无需安装 Node、npm 或开发工具。
需要已安装 Microsoft Edge 或 Google Chrome；界面与 PDF 导出使用本机字体，不请求在线字体。
没有自动更新或在线安装步骤。模型生成及资料检索使用网络和用户自己的模型配置。
应用地址固定为 http://127.0.0.1:5186/，仅本机访问。端口冲突时会报错，不连接其他服务。
重复点击启动会复用当前服务；停止命令只停止此资料包启动并核实身份的服务。

本包资料
描述性统计联合资料包，默认不编入学习树，内含三份公开资料的选编：
- 教材节选：26 页。
- 数值数据课件：25 页。
- 分类数据课件：10 页。
只包含该课程；不包含开发者的其他论文、个人笔记、画像、学习树任务、API Key 或运行日志。
两套内置讲述模板与其固定样稿属于程序功能，保持当前版本设置。
原作者、来源、原始页码、修改和许可说明见 materials/ATTRIBUTION.txt 与 SOURCES.json。
本产品不是 OpenIntro 官方产品，也不表示 OpenIntro 对本产品的认可或背书。

数据保存与迁移
首次运行才会创建 data 目录。模型设置写入 data/.env，笔记与个人模板保存在 data/browser
中的独立浏览器配置，理想学习树任务保存在 data/ideal-trees，启动日志在 data/logs。
应用分类诊断可能另写入 app/.cache。不会使用日常浏览器的个人配置。
请始终从 Start.cmd 打开，以免误入普通浏览器中另一个笔记库。
移动程序前先关闭窗口并停止服务。更换电脑时请通过应用的笔记备份功能迁移，原始 PDF
另存一份；浏览器配置中的加密数据不保证可跨 Windows 账户直接搬运。
分享给别人请发送最初的干净 ZIP，勿重新压缩使用过的目录：使用后会有你的 Key 和笔记。

当前边界
进入联合资料包后，可点击“新建笔记”，填写名称和整理要求；默认参考当前包及下属包全部原始资料。可分别生成讲义或练习笔记，也可直接打开每份资料自己的笔记。模型生成内容需核对重要事实与答案。
模型输出仍需核对原文，程序的格式与来源定位校验不保证所有讲解正确。
此包没有安装器或数字签名，不修改系统服务、开机启动项或注册表。
