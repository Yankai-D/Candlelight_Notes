烛光笔记 Candlelight · Windows 桌面版
Candlelight Notes

双击 Setup 安装程序，按向导安装。之后从桌面或开始菜单中的“烛光笔记 Candlelight”打开。
已包含阅读与 PDF 导出引擎，无需安装 Node、npm、Chrome 或 Edge。
首次打开依次展示学习画像与 DeepSeek 连接，两步都可直接“跳过”。画像从空白开始，由你自行填写。
进入后可在“根系”中维护画像，在“设置 → 模型连接”中保存自己的 API Key；未配置时可浏览原文和编辑笔记。
侧栏“?”、F1 和“帮助 → 使用说明”打开同一份分主题指南，包含功能入口、导出说明与常见问题。

关闭与保存
关闭窗口或选择“文件 → 退出烛光笔记”会先保存笔记，再停止应用。
任务进行中会询问是否暂停退出；完成的章节保留，下次可继续。重复打开只显示已有窗口。
尚未确认写入的 AI 建议不属于已保存正文，退出前请确认或放弃。
电脑强制关机、断电和操作系统强制结束进程无法执行正常退出流程；请定期导出重要笔记。

数据与更新
资料与笔记默认保存在 Windows“文档／烛光笔记”。每次导入前显示保存路径，可选择其他文件夹；成功导入后，下次沿用上次路径。
“设置 → 资料存储”也可更改后续导入位置；已有文件继续保存在原位置。资料按独立文件保存，笔记文件为 note.candlelight.json；理想学习树及其下载资料位于资料目录的 .candlelight 文件夹。
%APPDATA%\PangzhuNotes 只保留路径索引、画像和偏好等应用信息，.env 保存模型连接。可从“帮助 → 打开本机数据目录”找到。
升级保留连接。正常卸载强制清除 API Key（含未完成写入的临时文件）、缓存和日志；用户资料、笔记及轻量索引保留。程序自带的描述性统计原文随卸载删除。
重装后使用索引寻找原文件，Key 需要重新填写。资料的“…”可仅移除记录或移入回收站，都保留磁盘文件；设置 → 资料存储 → 资料备份与恢复可找回记录，只有回收站再次确认的永久删除才删除笔记、管理的原文副本及本空间生成记录。独立备份和最初导入的外部文件保留。
旧版资料首次打开会迁移，回读校验成功后才清除旧副本。若迁移尚未完成就卸载，旧资料数据库会暂时保留以防丢失；Key 仍会清除。
启动后会在后台检查 GitHub 发布版本，也可使用“帮助 → 检查更新”。发现新版可打开发布页下载、稍后处理或跳过该版本；检查失败不影响使用。更新前退出应用，再运行新版安装包；已有安装目录会直接复用，不重复追加产品文件夹。不会自动下载或执行安装包。
导入支持多选与整个文件夹，保留嵌套层级；新文件夹作为联合资料包。批量默认只保存原件，单文件也可选择不自动生成笔记。新建独立笔记时填写整理要求，系统才读取当前包及下属包的资料，例如分别创建完整复习讲义和例题题解，不必逐个生成资料笔记。读取结果缓存供后续复用。
文件短暂被同步程序占用、模型连接暂时中断时会有限自动重试；诊断日志失败不阻止有效结果。持续无法写入、磁盘已满或 Key 无效仍会明确提示，保留已完成内容。帮助菜单中的本机数据目录包含 logs 恢复日志。
启动时识别“文档／烛光笔记”、当前保存位置及用户记住的识别目录。资料库或“设置 → 资料存储”中的“识别已有笔记”支持选择其他目录、预览并关联已有笔记，正文、纸条、版本和修改记录继续保留，不复制文件、不调用 AI 生成。
识别对象是 note.candlelight.json 及配套原文。编号冲突时不覆盖；原位置失效后，可扫描新位置更新关联。原文缺失时允许只读查看已有笔记。被移除的记录不会在下次启动时自动加回，可通过手动识别恢复。
多个应用共用笔记文件时，检测到文件已被另一应用改动会拒绝覆盖。“处理保存冲突”可以查看两份节选，把当前修改另存为新笔记，或确认使用磁盘版本。原文缺失时可以重新选择原文件，现有笔记保留。各应用的画像、API Key 和个人设置保持独立。普通 PDF/Markdown 与导出的 JSON 备份请通过“导入资料”添加。
设置 → 资料存储 → 资料备份与恢复可创建完整备份文件夹，包含原文、全部阅读版本、画像、模板、分类与学习树，不含 API Key。恢复前先检查文件并预览，复制到新目录后再切换；可返回上一个学习空间。请勿同时在多个应用进程内对共享目录进行整库维护。
阅读界面“修改记录”中的生成记录保留目标、画像、模板、调用及修复信息；格式校验通过不代表事实已被人工审定。记录含学习内容，应作为私人资料保管。
分享请发送原始安装程序，不发送个人数据目录。尚存于旧浏览器 IndexedDB 的资料需先在自用版完成文件迁移，之后安装版才能通过资料目录识别。

本包只预装描述性统计三份公开资料，无个人论文、笔记、画像或 API Key。
原文作者、来源、原始页码和改编许可见 resources/materials/ATTRIBUTION.txt。
项目致谢见应用“帮助 → 关于与致谢”及 resources/ACKNOWLEDGEMENTS.md；依赖清单见 resources/THIRD-PARTY-NOTICES.txt。
OpenIntro 未对本产品背书。Node/Chromium/Electron 与 npm 依赖许可随程序保留。
本项目尚未指定开源许可证。本安装程序没有开发者数字签名。

联合资料包可嵌套学科与单元。包内可点击“新建笔记”，填写名称与整理要求，默认参考当前包及下属包全部资料；可创建多份笔记，并在“…”中修改资料或笔记名称。资料笔记与独立笔记分别保存。
独立笔记按来源规划后逐章生成，中断可继续。来源随笔记保存，原文对照可切换文件；新增文件不自动重写已有笔记。重新生成沿用保存的来源，新资料请另建笔记。模型生成的讲义或练习仍需核对重要事实与答案。
